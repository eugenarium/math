# Матбук

Интерактивный учебник вузовской математики и статистики для телефона. Статическое PWA: работает офлайн, прогресс хранится на устройстве, сервера нет. Уроки — короткие декларативные YAML-записи, которые массово пишут недорогие модели, а проверяет машина.

**Охват по карте курса:** 208 уроков в 14 разделах; ядро — 128 уроков, около 45 часов; всё вместе — около 74 часов. **Готово:** 29 уроков: 4 эталонных (`c1.riem`, `c1.der`, `la.eig`, `st.ci`), весь раздел «Подготовка» (8) и семнадцать уроков анализа: `c1.lim`, `c1.cont`, `c1.rules`, `c1.int`, `c1.chain`, `c1.sub`, `c1.parts`, `c1.opt`, `c1.limcalc`, `c1.lhop`, `c1.mvt`, `c1.seq`, `c1.small`, `c1.impl`, `c1.study`, `c1.ftc`, `c1.impr`.

## Содержимое

```
schema/            lesson.schema, problem.schema (JSON Schema 2020-12 в YAML)
content/ref/       notation, style, glossary, errors
content/cards/     карточки уроков (samples.yml — эталоны, pre.yml — «Подготовка», c1.yml — анализ)
content/lessons/   уроки: c1.riem, c1.der, la.eig, st.ci (эталоны), весь раздел pre и c1.lim, c1.cont, c1.rules, c1.int, c1.chain, c1.sub, c1.parts, c1.opt, c1.limcalc, c1.lhop, c1.mvt, c1.seq, c1.small, c1.impl, c1.study, c1.ftc, c1.impr
engine/core/       ядро: генераторы, шаблоны, проверка ответов, критерий усвоения, повторения (srs), прогресс
engine/widgets/    виджеты: fplot, riemann, lin2, dist, ci, matrix, venn, numline, complex (остальные из docs/WIDGETS.md — по плану)
engine/ui/         плеер урока (Preact): главная, экраны фаз, задачи, клавиатуры, хост виджетов, настройки
public/            иконки приложения (icon.svg и PNG для манифеста)
tools/build.mjs    YAML → JSON с проверкой схем (подключается к Vite как virtual:content)
tools/check.mjs    линтер контента: коды E и W, прогон 200 наборов чисел на каждую задачу
tools/check/       проверки схем, карты курса и эталонных уроков (Python)
```

## Команды

```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
pip install -r tools/check/requirements.txt
node tools/check.mjs [id|раздел]   # линтер контента (коды E блокируют, W — предупреждения)
npm test           # тесты ядра и линтера
npm run check      # линтер, тесты, карта курса, эталонные уроки
```

Проверки в `tools/check/*.py` остались как независимая перекрёстная проверка карты курса и эталонных уроков.

## Публикация

CI на каждый push прогоняет проверки и сборку. С ветки `main` сайт публикуется на GitHub Pages; в настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

## Состояние

Сделано: документация, схемы DSL, справочники, шестнадцать уроков, ядро движка (`gen`, `check`, `mastery`, `srs`, `store`, `plot`), плеер урока, виджеты `fplot` и `riemann`, линтер контента, CI и публикация.

Работает:
- шесть фаз урока, задачи `num`, `mc`, `expr`, `spot`, `graph`, `sim` с автопроверкой и диагностикой заблуждений;
- критерий усвоения и сохранение прогресса;
- повторения с интервалами 1 → 3 → 7 → 16 → 35 → 80 → 180 дней: сессия дня (до 10 уроков по 3 задачи вперемешку), оценка 3/3, 2/3, 0–1 из 3;
- экзамен экстерном («я это знаю»): 4 задачи максимального уровня без подсказок, при успехе повторение через 7 дней;
- главная: кнопка повторений, предупреждение о долге больше 20 уроков, рекомендация следующего урока;
- линтер: коды E101–E403 и W502–W508 (кроме W504), проверка идёт в CI;
- офлайн-режим (PWA): манифест, сервис-воркер с предзагрузкой оболочки и ленивых чанков виджетов, установка на домашний экран, запрос постоянного хранилища;
- «Прогресс и копия»: сохранение прогресса в файл `.json`, загрузка из файла, сброс; напоминание о копии раз в 30 дней.

Пока нет: задач `proof`, боссов и игрового слоя, остальных виджетов каталога (в готовых уроках заглушек больше нет).
Дальше: остальные уроки `c1` (`c1.seq`, `c1.limcalc`, `c1.chain`, `c1.mvt` и далее), раздел `lg`, задачи `proof`.

## Установка на телефон

Открой сайт в Safari (iPhone: «Поделиться» → «На экран Домой») или в Chrome (Android: меню → «Установить приложение»). После первого запуска с сетью приложение работает без интернета. Прогресс хранится на устройстве: сохраняй копию в «Прогресс и копия».
