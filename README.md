# Матбук

Интерактивный учебник вузовской математики и статистики для телефона. Статическое PWA: работает офлайн, прогресс хранится на устройстве, сервера нет. Уроки — короткие декларативные YAML-записи, которые массово пишут недорогие модели, а проверяет машина.

**Охват:** 208 уроков в 14 разделах; ядро — 128 уроков, около 45 часов; всё вместе — около 74 часов.

## Содержимое

```
schema/            lesson.schema, problem.schema (JSON Schema 2020-12 в YAML)
content/ref/       notation, style, glossary, errors
content/cards/     карточки уроков
content/lessons/   уроки: c1/c1.riem, la/la.eig, st/st.ci — эталоны
engine/core/       ядро: генераторы, шаблоны, проверка ответов, критерий усвоения, прогресс
engine/ui/         плеер урока (Preact): главная, экраны фаз, задачи, клавиатуры
tools/build.mjs    YAML → JSON с проверкой схем (подключается к Vite как virtual:content)
tools/check/       проверки схем, карты курса и эталонных уроков (Python)
```

## Команды

```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
pip install -r tools/check/requirements.txt
npm test           # тесты ядра: форматы, генераторы, проверка ответов, 200 наборов на каждую задачу
npm run check      # контент, тесты, карта курса, эталонные уроки
```

Проверки на Python — временные: в плане их заменяет `tools/check.mjs` (этап 0, шаг 2:00–2:30).

## Публикация

CI на каждый push прогоняет проверки и сборку. С ветки `main` сайт публикуется на GitHub Pages; в настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

## Состояние

Сделано: документация, схемы DSL, справочники, три эталонных урока, ядро движка (`gen`, `check`, `mastery`, `store`), плеер урока, CI и публикация.

Работает: шесть фаз урока, задачи `num`, `mc`, `expr`, `spot` с автопроверкой и диагностикой заблуждений, критерий усвоения, сохранение прогресса.

Пока нет: виджетов (в уроках показывается заглушка с заданием), задач `graph`, `sim`, `proof` (в практику не попадают), повторений, линтера `check.mjs`.
Дальше по `docs/PLAN.md`: `plot.js` и виджет `fplot`, линтер E/W.
