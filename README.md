# Матбук

Интерактивный учебник вузовской математики и статистики для телефона. Статическое PWA: работает офлайн, прогресс хранится на устройстве, сервера нет. Уроки — короткие декларативные YAML-записи, которые массово пишут недорогие модели, а проверяет машина.

**Охват по карте курса:** 208 уроков в 14 разделах; ядро — 128 уроков, около 45 часов; всё вместе — около 74 часов. **Готово:** 86 уроков: `st.ci` и одиннадцать уроков статистики (`st.descr` … `st.test`, `st.zt`, `st.two`, `st.power`, `st.chi`, `st.reg`), пятнадцать уроков линейной алгебры (`la.vec` … `la.rank`, `la.cob`, `la.diag`, `la.orth`, `la.proj`, `la.sym` и `la.eig`), весь раздел «Подготовка» (8), шесть основных уроков дискретной математики (`dm.count`, `dm.perm`, `dm.binom`, `dm.stars`, `dm.incl`, `dm.rec`) и семнадцать основных уроков теории вероятностей (`pr.space` … `pr.norm`, `pr.joint`, `pr.cov`, `pr.ineq`, `pr.lln`, `pr.clt`), весь раздел «Анализ: одна переменная» (`c1`, 22) и пять основных уроков логики (`lg.prop`, `lg.impl`, `lg.equiv`, `lg.quant`, `lg.proof`).

## Содержимое

```
schema/            lesson.schema, problem.schema (JSON Schema 2020-12 в YAML)
content/ref/       notation, style, glossary, errors
content/cards/     карточки уроков (samples.yml — эталоны, pre.yml — «Подготовка», c1.yml — анализ)
content/lessons/   уроки: c1 (22), pre (8), lg (5 основных), la (15 и la.eig), dm (6 основных), pr (17 основных), st (11 и st.ci), st.ci
engine/core/       ядро: генераторы, шаблоны, проверка ответов, критерий усвоения, повторения (srs), прогресс
engine/widgets/    виджеты: fplot, riemann, lin2, dist, ci, matrix, venn, numline, complex (остальные из docs/WIDGETS.md — по плану)
engine/ui/         плеер урока (Preact): главная, экраны фаз, задачи, клавиатуры, хост виджетов, настройки
public/            иконки приложения (icon.svg и PNG для манифеста)
tools/build.mjs    YAML → JSON с проверкой схем (подключается к Vite как virtual:content)
tools/check.mjs    линтер контента: коды E и W, прогон 200 наборов чисел на каждую задачу
tools/check/       проверки схем, карты курса и эталонных уроков (Python)
```

## Команды

```bash
npm install
npm run dev        # локальный сервер
npm run build      # сборка в dist/
pip install -r tools/check/requirements.txt
node tools/check.mjs [id|раздел]   # линтер контента (коды E блокируют, W — предупреждения)
npm test           # тесты ядра и линтера
npm run check      # линтер, тесты, карта курса, эталонные уроки
npm run check:answers  # независимый пересчёт ответов числовых задач (перебор, численный анализ)
```

Проверки в `tools/check/*.py` остались как независимая перекрёстная проверка карты курса и эталонных уроков.

## Публикация

CI на каждый push прогоняет проверки и сборку. С ветки `main` сайт публикуется на GitHub Pages; в настройках репозитория нужно один раз выбрать **Settings → Pages → Source: GitHub Actions**.

## Состояние

Готово 86 уроков из 208 по карте; 9 виджетов из 34; типы задач num, mc, expr, spot, proof, graph, sim; повторения, экзамен, экспорт прогресса, QR и ссылка на приложение. Подробности — в [docs/STATUS.md](docs/STATUS.md), остаток — в [docs/BACKLOG.md](docs/BACKLOG.md).

Работает: шесть фаз урока, автопроверка и диагностика заблуждений, критерий усвоения, повторения с интервалами и экзамен экстерном, офлайн-режим (PWA), экспорт и импорт прогресса, QR-код и ссылка на приложение (экран «Прогресс, копия, поделиться»).

## Установка на телефон

Открой сайт в Safari (iPhone: «Поделиться» → «На экран Домой») или в Chrome (Android: меню → «Установить приложение»). После первого запуска с сетью приложение работает без интернета. Прогресс хранится на устройстве: сохраняй копию в «Прогресс, копия, поделиться».
