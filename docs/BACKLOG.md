# BACKLOG — что осталось

Порядок внутри блока — рекомендуемый. Точные списки уроков и виджетов — в [STATUS.md](STATUS.md) (строятся автоматически).

## 1. Проверить и закрыть долги

1. Просканировать QR на реальном телефоне (iOS и Android); при сбое — поднять версию/маску или добавить режим ECC L.
2. Подтвердить, что на установленной PWA блок «Поделиться» появляется после перезапуска; при необходимости добавить в настройки кнопку «Проверить обновление».
3. Прогнать в браузере 6 старых уроков с задачами `graph` (остальные 76 прогнаны).
4. Убрать предупреждение W502 в `la.eig`.
5. Чек-лист на телефоне по выборке готовых уроков (делает владелец, PLAN — «Ты»).

## 2. Недостающие виджеты

- **P0:** все реализованы; недостающие режимы (см. WIDGETS): `vec2 comb`, `sample boot`, `chance` — остальные опыты, `bayes` — другие виды, `scatter drag/poly/logit/box`, графы для gr, линии условного среднего в `contour`.
- **P1:** все реализованы (часть режимов — см. WIDGETS); они ждут уроков разделов sr, de, nm, op.
- **P2:** `pascal`, `pca`, `cgraph`. **3D:** `surf3`, `vec3`, `lin3`, `vol3`.
- После каждого виджета — точечный патч уроков, у которых карта предусматривает ★ (26 готовых уроков, список в STATUS).

## 3. Ядро курса, которого нет

Разделы `gr` (6), `sr` (5), `cm` (10), `op` (6), `de` (7), `nm` (8). Начатые разделы (pre, lg, c1, la, dm, pr, st) закрыты целиком, включая расширения и опции. В `ml` уроков ядра нет, только расширения.

## 4. Расширения и опции

Расширения и опции разделов pre, lg, c1, la, dm, pr, st сделаны. Остальные — по разделам в STATUS. Порядок из PLAN для оставшихся: ml → op → nm → de → cm → gr → sr.

## 5. Игровой слой (PLAN, этап 4)

XP, уровни, серии → боссы разделов → мини-игры «Спринт», «Сыщик», «Мишень», «Глазомер», «Сборка», «Пары» → `pairs.yml`.

## 6а. Заметки от руки: распознавание

Рисунок уже есть. Распознавание в текст/LaTeX — варианты (выбрать после проверки размера и качества):
1. Только цифры и знаки (0–9, +, −, /, .) для ввода ответа от руки: лёгкий офлайн-распознаватель без библиотек.
2. Офлайн-модель распознавания формул в браузере (десятки МБ; нужно решение по размеру кэша PWA и по установке пакета).
3. Внешний сервис: нужен интернет, рисунок уходит на чужой сервер — только по явному согласию.
Также: заметка к конкретной задаче, цвет фона листа, вставка рисунка в копию как PNG.
