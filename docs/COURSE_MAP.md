# COURSE_MAP — карта курса

Источник истины для карточек (`content/cards/*.yml`). Проверяется `tools/lint` (ссылки, циклы, приоритеты).

## Как читать

- **id** = `раздел.тема`; он же имя файла урока.
- **Зависит от**: `↑` — от предыдущей строки раздела (значение по умолчанию, чтобы не повторять цепочки); остальные id — дополнительные предпосылки. `—` — без предпосылок.
- **П** (приоритет): **Я** ядро · **Р** расширение · **О** опционально. Правило: ядро зависит только от ядра, расширение — от ядра и расширения.
- **мин** — время первого прохождения (без повторений).
- **Метки**: `★ виджет` — здесь интерактив даёт наибольший эффект; `3D` — тема, где оправдана трёхмерная сцена; `⚠` — частое заблуждение (обязано попасть в `content/ref/errors.yml` и в фазу `err` урока).

| | **Итого** | | **128/66/14 = 208** | **≈45 / ≈74** | |

С повторениями и боссами закладывай ×1.5 ко времени.

**Решения по охвату.** Добавлен раздел `pre` (без него ε–δ, Σ и логарифмы рвут ядро). Логика разделена: база — в ядро и рано (кванторы и доказательства нужны анализу), формальные системы — в расширение. Ряды — отдельный короткий раздел. Векторный анализ, Жорданова форма, потоки, УрЧП, теория оценок, EM и SVM — опционально: дорогие в объяснении, редко нужны дальше. Теория меры, функциональный анализ, ТФКП, топология не включены: интерактив почти не помогает, а объём большой.

**Маршруты.** Движок открывает любой урок с пройденными предпосылками, поэтому маршрут — рекомендация:
- *Основной:* две линии параллельно. A: pre → c1 → sr → cm → op → de. B: lg → la → dm → gr → pr → st → nm. Чередование линий полезно само по себе (интерливинг).
- *Быстро к статистике:* pre → lg (до lg.quant) → dm.count…dm.binom → c1 (ядро) → pr (ядро) → st (ядро). 55 уроков, ≈19 ч.
- *К ML:* основной маршрут по ядру la, c1, cm, pr, st, op → ml.

## Где 3D оправдано

Только там, где объект по сути трёхмерный и плоская картинка его искажает:

| Сцена | Темы |
|---|---|
| `surf3` | cm.fn, cm.part, cm.diff, cm.extr, la.quad |
| `vec3` | la.sys (три плоскости), la.space, la.basis, la.proj, la.cross |
| `lin3` | la.det (объём), la.rank (схлопывание в плоскость или прямую) |
| `vol3` | cm.dint, cm.tint, c1.app (тела вращения) |

В остальных темах 3D не используется. Градиентный спуск, Лагранж и совместные плотности показываются на `contour`: на телефоне карта уровней читается лучше поверхности.

## Боссы разделов

Босс раздела открывается, когда пройдены все уроки ядра этого раздела; расширенный босс — когда пройдены ещё и уроки расширения. Отдельного контента не требуют (см. ARCHITECTURE.md).
